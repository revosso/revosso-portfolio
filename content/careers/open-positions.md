# Revosso Open Positions

This file is the source of truth for job listings on https://revosso.com/careers.

## How to use this file

1. Add a new job by copying an existing job section below, including the HTML comment that precedes it.
2. Give the job a unique `id` and `slug` (lowercase, hyphenated).
3. Fill in the YAML fields. Use `null` for anything that is not confirmed yet.
   Do not invent salary, location, employment type, benefits, or deadlines.
4. Write the longer overview in Markdown below that job’s YAML frontmatter.
5. Publish, unpublish, or close using the flags below. Rebuild or redeploy the site
   for changes to appear.

### Publish a position

```yaml
status: open
published: true
```

### Unpublish / hide a position

```yaml
published: false
```

### Close a position

```yaml
status: closed
published: false
```

### General applications (empty-state CTA)

Set `generalApplicationEmail` or `generalApplicationUrl` in the YAML at the top of
this file when you want a “send a general application” button on the Careers page
while no roles are listed. Leave them `null` otherwise.
